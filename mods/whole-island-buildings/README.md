# whole-island-buildings

全岛只需一座公共建筑即可满足需求。原作 GlacialPigeon69（mod.io `3294467`）。

- **ModID**：`local-whole-island-buildings`
- 45 条 ModOp，覆盖旧世界 & 崔老妮、新世界、安贝萨、北极的公共建筑

| 属性 | 含义 | 值 |
|---|---|---|
| `FullSatisfactionDistance` | 完全满足距离 | `995` |
| `NoSatisfactionDistance` | 完全无效距离 | `1000` |
| `IndustrializationDistance` | 电力 / 工业化覆盖 | `1000` |
| `BaseStreetRange` | 总督府街道范围 | `1000`（每模块 +`100`） |
| `ProductionBuffDistance` | 生产加成距离 | `175` |
| `SocketScopeRadius` | 模块作用半径 | `125` / `150` / `250` |
| `HaciendaRadius` | 新世界庄园半径 | `200` |
| `HeatRange` | 北极加热器 | `1000` |
| `ActivationRadius` | 公交站 | `175`（街道 `1500`） |

## 注意

只改满意度、供电、街道、供暖这类距离字段，与改港口范围或商人池的 mod 不冲突。
