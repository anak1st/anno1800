## 改了什么

共 **49 条 `ModOp`**（7 个 `replace` 整体替换 7 个商人的 `RewardPool` + 42 个 `merge` 设 `MaxItemsToOffer`），把原本锁定的物品全部放进可交易池。

- 共 **1453 个 `<ItemLink>`** 条目，每条的 `<Weight>` 多为 `10`
- 涉及 **7 个商人**：Sir Archibald Blake、Eli Bleakworth、Madame Kahina、
  Isabel Sarmento、Old Nate、Qumaq、Emperor Ketema
- 另有 42 处 `MaxItemsToOffer`（值 512）、7 处 `IgnoreUnlocks`（忽略解锁条件）
- 各家条目数：萨曼托 336 ｜ 伊莱 332 ｜ 卡希纳 282 ｜ 布莱克 216 ｜ 柯提马 102 ｜ 老奈特 101 ｜ 库马克 84
- **原版商人能买的 1154 张，这里一张不漏**（`原版卖 ∧ mod 没卖` = 0）；另外 292 张只有本 mod 能买
- **剧本专用的卡一张都不卖**（这 mod 面向沙盒；剧本卡要 `ScenarioFilter` 生效的剧本才有用）
- 1446 张卡对应 1453 条：**7 张跨新世界+安贝沙的生产卡两边都挂**（见下面规则 5+7），
  其余每张卡只挂一家；**每个池内也没有重复条目**
- 每个商人的 `ItemsPool` **两层分组**：顶层大类 **建筑 / 载具 / 娱乐 / 其他**，下面再按细类
  （市政厅 / 工会 / 港务总管办公室 / 博物馆 / 动物园 / 植物园 / 船只 / 军舰 / 飞船 / 打捞船 /
  地图 / 北极小屋 …，与 [`docs/cards.md`](../../docs/cards.md) 同一套归类），类内按英文名排序；
  每组一行注释，商人的抬头也重写了（带大类计数）

## 收录范围（哪些卡进池）

**三个游戏结构判据**（`src/anno/rules.py` 的 `in_mod()`）：

1. 原版商人卖过（游戏档位池能展开到）；
2. 研究所可研发；
3. 老奈特可合成。

合计 **1426 张**。**剧情 / 活动 / 战役奖励默认不进池** —— 它们原版没人卖、不可研发、也不能合成，
本来就不该由商人出售（例如金银铜表现奖章、鱼雷、女王的字条）。

例外是一张**人工审核名单**（`MANUAL_INCLUDES`，20 张，逐张确认要卖）：

- 纳达斯基司令的军刀 `112825`、纳达斯基的勋章 `113473`（向传奇致敬）
- 崔老妮老兵霍加斯 `113792`（向传奇致敬）
- 苏珊娜 `113799`、费尔南多 `113800`（大型展览）
- 女王的黑帝斯号仿制品 `114795`、特别好拉的滑轮 `116174`（救命之恩）
- 瓦哈德瑟的古老石板 `130777`（先知纪念碑的祝福）
- 安贝沙编年史（Legendary）`130937`（狮子史诗）

所以实际是 **1426 + 20 = 1446 张**。卡池由这套规则**算出来**：`build_db.py` 也用它给
`data/cards` 打「本 mod 谁卖」的标签，所以文档和卡池不会对不上。

> **规则 5–7 只看殖民地，且跨区的生产卡双挂**：
>
> 1. **旧世界不参与区域规则** —— 布莱克 / 伊莱 / 卡希纳 是按职能分的（海军 / 生产 / 城市），
>    所以只有「目标完全不碰旧世界」的卡才按区域归区。
> 2. **跨区不二选一** —— 游戏的目标组会跨区：池 `125109`「所有安贝沙作物农场」除了 5 座
>    安贝沙农场，还挂着新世界的「庄园辛香料农场」；「安贝沙使节」更是直接点了新世界 4 座工厂
>    + 安贝沙 3 座农场。这类卡在游戏里**两个世界都用得上**，所以两边都挂，谁都不用抢。
> 3. **只给生产卡双挂** —— 娱乐 / 住所 / 市政厅这类跨区卡仍按功能规则归一家。
>
> 目前双挂的 7 张（全部 狮子大地 DLC）：鸟屋、蚊帐、叶贝巴的坚固温室、花朵之女、卡拉·莉莉、
> 香料大师、安贝沙使节 → **柯提马 + 萨曼托** 两家都有卖。

> 规则实现在 `src/anno/rules.py`（收录范围 `in_mod` + 归属）。**单向流程**：游戏文件 → `build_db.py`
> → `data/` → `build_cards.py` → 文档；卡池是本流程的输出，用 `uv run edit_pools.py assign [--dry-run]`
> 从规则重建（默认不读文件旧内容，`--keep` 才叠加），然后把 `mods/` 同步到游戏目录。
> `build_db.py` **不读** `assets.xml` —— 文档里的「本 mod 谁卖」也是同一套规则算出来的。

### 故意没收录的

- **剧本专用**：带 `ScenarioFilter` 的卡（伊甸浴火 / 剧本 3 / 剧本 4），沙盒里没用
- **任务道具 / 战役奖励**：只挂在剧本或战役「补给包」池上的物品
  （`Care Package GGJ` / `Export Master` / `Seasons of Silver` / `Clash of Couriers`）
- 逐张清单见 [`docs/cards-special.md`](../../docs/cards-special.md)

> **与原版 mod.io 版本的差别**：原版是 9 个商人 / 1663 条（含两个海盗
> Anne Harlow 池 `192070`、Jean La Fortune 池 `192071`）。本备份移出这两个海盗
> （1663 − 133 = 1530），并按上面这套规则整体重排为 **1453 条**（1446 张卡，含 7 张双挂）。

> 计数口径：真实条数是 **49**（`replace` 7 + `merge` 42），数带空格的 `<ModOp ` 即可。
> `<ModOps>` 里含子串 `<ModOp`，直接数 `<ModOp` 会多算 1 条（旧文里「63 / 64 条」的说法就是这么来的）。
