# all-items-unlocked

解锁所有商人出售的全部可装备物品。原作 Iksaandry（mod.io `4302450`，`1.2`）。

- **ModID**：`AllItemsUnlockedAtTraders`
- **49 条 ModOp**：7 个 `replace` 整体替换 7 个商人的 `RewardPool`，42 个 `merge` 设 `MaxItemsToOffer = 512`
- **1453 条 `<ItemLink>`**，覆盖 **1446 张卡**，其中 7 张跨新世界 + 安贝沙的生产卡两家都挂

| 商人 | 条目 |
|---|---|
| 萨曼托（新世界） | 336 |
| 伊莱（旧世界） | 332 |
| 卡希纳（旧世界） | 282 |
| 布莱克（旧世界） | 216 |
| 柯提马（安贝沙） | 102 |
| 老奈特（崔老妮） | 101 |
| 库马克（北极） | 84 |

## 收录范围

三个判据任一即可：原版商人卖过、研究所可研发、老奈特可合成，共 1426 张。另加 20 张人工确认名单（`MANUAL_INCLUDES`，如纳达斯基的军刀 / 勋章、苏珊娜、女王的黑帝斯号仿制品），合计 1446 张。

剧情 / 活动 / 战役奖励不进池；带 `ScenarioFilter` 的剧本卡也不进。

## 归属规则

按作用区域分，先命中先赢。规则实现在 `src/anno/rules.py`，卡池由 `edit_pools.py assign` 重建。

| 类别 | 归谁 |
|---|---|
| 海军、船只、港务总管办公室 | 布莱克 |
| 飞船 | 库马克 |
| 打捞船、地图 / 探险点 | 老奈特 |
| 只影响安贝沙 | 柯提马 |
| 只影响北极 | 库马克 |
| 只影响新世界 | 萨曼托 |
| 跨新世界 + 安贝沙的生产卡 | 两家都挂（7 张） |
| 娱乐展品 | 按 DLC 归当地商人，本体 / 植物园归萨曼托 |
| 生产 | 伊莱 |
| 人口、市政厅、商业餐饮 | 卡希纳 |
| 无装槽的其他物品 | 萨曼托 |

> 与原版 mod.io 版的差别：移出两个海盗（Anne Harlow、Jean La Fortune）的池，条目从 1663 重排为 1453。
