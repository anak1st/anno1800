# mr-long

同一个 mod 里的两张「传销头子」卡：

| 卡 | 装槽 | GUID | 状态 |
|---|---|---|---|
| 传销头子法瑞斯·阿瑟雷密 | 工会 | `1400000006` | 已使用 |
| 传销头子（北极版） | 北极小屋 | `1400000008` | 新加，未验证 |

- **ModID**：`local-mr-long`
- **LoadAfterIds**：`local-all-items-unlocked`（不要删）

## 卡一（工会）

| 属性 | 数值 |
|---|---|
| 生产力 | +300% |
| 维护费 / 人力 | −75% |
| 暴动 / 火灾 / 疾病 / 爆炸 | −99% |
| 自带电力 | `Powerplant` |
| 售价 | 1000 / 50 线上 |
| 远征 | 男性、外交 20、催眠师 |

作用对象是 5 个生产类目标组（`193856`、`194008`、`194011`、`194023`、`194024`），不含北极。获取方式是放进 8 个 NPC 的奖励池，权重 100。

## 卡二（北极小屋）

| 属性 | 数值 |
|---|---|
| 生产力 | +300%（含天然气） |
| 维护费 / 人力 | −75% |
| 火灾 / 爆炸 | −99% |
| 售价 | 1000 / 50 线上 |
| 远征 | 医学 30、制作 30、狩猎 15、信仰 10、男性 |

作用对象只有所有北极生产建筑 `193770`（18 座）。获取方式是库马克 `193835` 的奖励池，权重 100。

两条刻意不写独立字段：天然气不单挂副产物，靠生产力 +300% 直接放大；「加人口」靠人力 −75% 等效实现，没有改住所。

## 注意

- 卡二依赖航道 DLC `410042`；防火 / 防爆字段未实测，若不生效删掉这两块即可。
- 卡一是原版 `192450`（生产力 +50%）的传奇克隆，两张可以同时持有。
- 与 `download/mods-mr-long/` 里的 V1.2 是同一个物品、同一 GUID `1400000006`，只能保留其一。
