## 备注

**`ScenarioFilter` 只标限定剧本**，与剧情模式（战役）无关 ——
战役物件（爆破专家 `100967`、卡彭权杖 `112272` 等）的该字段都是空的。

判定「是否真专用」可以参考：

| 信号 | 含义 |
|---|---|
| 内部名带 `S03 Lost Item` / `Sceanrio04` / `Enactment` | 明确是剧本内容 |
| 效果项 = 0 | 没有作用，游戏里是废卡 |
| `TradePrice` = 0 | 游戏不把它当商品 |
| 原版交易商池有引用 | 常规玩法里就能拿到 |
